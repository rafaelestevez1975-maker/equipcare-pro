📲 Como instalar como App no celular

iPhone / iPad (Safari)
Abra o link no Safari → toque em Compartilhar ↑ → "Adicionar à Tela de Início" → Adicionar
🤖
Android (Chrome)
Abra o link no Chrome → toque em ⋮ → "Adicionar à tela inicial" → Adicionar
💻
Computador (Chrome ou Edge)
Abra o link → clique no ícone ⊕ na barra de endereço → Instalar
✉️ Primeiro Acesso — Como funciona
O administrador envia um convite por e-mail diretamente pelo sistema.
Você receberá um link único de rafael@lasercompany.com.
Clique em "Ativar Meu Acesso", crie sua senha e pronto — o sistema estará disponível em todos os seus dispositivos!
🔐 Segurança
Cada usuário tem login individual e senha própria.
Dados armazenados em nuvem segura (Supabase / AWS). Todos os acessos são registrados em auditoria automática.
